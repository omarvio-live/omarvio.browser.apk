# OMARVIO BROWSER — Global Edition

> **"আমার ফোন, আমার ডেটা – কাউকে দেব না!"**  
> **Zero Telemetry · Zero Central User Database · Ad-Free Parallel Search · World AI + Local On-Device AI · Cross-Platform Parity**

OMARVIO BROWSER is a global privacy-first web browser built for everyone worldwide across **Android APK/AAB**, **Windows PC (`.exe`)**, **Linux Desktop (`.AppImage` & `.deb`)**, and **Web PWA** (`https://omarvio-browser.pages.dev`).

---

## Why Use OMARVIO BROWSER? (কেন ওমারভিও ব্রাউজার ব্যবহার করবেন?)

1. **100% On-Device Data Ownership:** No central surveillance database, no admin tracking panel, no analytics SDKs, and no behavioral ad profiling. Bookmarks, tabs, history, downloads, and encrypted vault secrets never leave your device.
2. **OMARVIO 7-Source Parallel Search (Zero Tracking):** Searches Google, DuckDuckGo, Brave, Bing, YouTube, Wikipedia, GitHub, and Stack Overflow in parallel using local-first and edge-cached fusion—delivering clean, accurate consensus results with zero user tracking.
3. **World AI Directory + Local On-Device AI:** Access **Built-in Instant AI**, **Browser Gemini Nano** (`window.ai`), **Local Ollama (`127.0.0.1:11434`)**, and direct 1-tap access to **12 leading World AI platforms** (ChatGPT, Google Gemini, Duck.ai, Claude, DeepSeek, Grok, Perplexity, Microsoft Copilot, Meta AI, Mistral Le Chat, Qwen Chat, and HuggingChat).
4. **Built-In Ad, Tracker, Phishing & HTTPS-Only Shield:** EasyList, EasyPrivacy, Privacy Badger heuristics, tracking-parameter stripping (`utm_*`, `fbclid`, `gclid`), and automatic HTTPS upgrades protect every session automatically.
5. **Same Experience Across Every Device:** Unified Omnibox, Back/Forward History Stack, Tab Sleeper, Energy Saver, Native Share, Offline Reader Mode, and Automatic Update Notifications across Android, Windows, Linux, and Web PWA.
