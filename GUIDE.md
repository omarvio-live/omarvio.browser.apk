**Worldwide Edition · Applies to Android APK, Windows PC, Linux Desktop, and Web PWA**

## 1. Getting Started Across Platforms

### Web PWA (`omarvio-browser.pages.dev`)
- Open directly in Chrome, Edge, Safari, or Firefox, or click **Install App / Add to Home Screen** for an app-like experience with offline reader fallback.
- Search immediately using **OMARVIO Smart** (7-source consensus search) or switch between Google, DuckDuckGo, Brave, Bing, YouTube, Wikipedia, GitHub, and Stack Overflow.

### Android APK (`com.omarvio.browser`)
- Download `omarvio-browser.apk` from the [Official Release Page](https://github.com/omarvio-live/omarvio.browser.apk/releases/latest).
- Tap **Open** to install. Future updates show an in-app **Update Banner** that downloads and opens the Android installer in one tap and **automatically clears** once the download finishes or your installed version is up to date.
- Features native **Pooled Chromium WebView**, **Biometric/PIN Privacy Vault**, **Background Audio**, **`.mht` Offline Page Saver**, and **Tap-to-Read Voice Reader**.

### Windows & Linux Desktop (`OMARVIO BROWSER Desktop`)
- **Windows:** Download either the NSIS Setup Installer (`.exe`) or Portable Edition (`.exe`).
- **Linux:** Run the universal `.AppImage` (`chmod +x` then double-click) or install the `.deb` package on Ubuntu/Debian (`sudo apt install ./OMARVIO-BROWSER-*.deb`).
- Desktop runs native **Chromium `WebContentsView`** directly from your computer with built-in request/tracker blocking, zero-proxy local parallel search, full Download Hub, and auto-clearing update notifications.

## 2. Smart Search & Privacy Shield Controls

- **7-Source Parallel Consensus Search:** Combines live results from Wikipedia, DuckDuckGo, GitHub, Stack Overflow, Google, Brave, and Bing without logging search queries or profiling you.
- **Direct Open vs Reader Proxy:** Websites open directly in Android & Desktop Chromium engines, while on Web PWA every search result offers both direct open (`ডাইরেক্ট`) and Reader Mode (`প্রিভিউ`) when cross-origin framing is restricted.
- **Ad & Tracker Shield:** Automatically blocks advertising scripts, cross-site trackers, known phishing/malware domains, and strips tracking tags (`utm_*`, `fbclid`, `gclid`, `mc_cid`).
- **HTTPS-Only Upgrade:** Automatically upgrades plain HTTP requests to encrypted HTTPS whenever available.

## 3. World AI Hub & Local On-Device AI

Tap **🤖 AI** from the Omnibox, Floating Action Menu, or Top Bar:
1. **Built-in Instant AI:** Fast factual & coding answers inside the browser.
2. **On-Device Gemini Nano (Chrome/Edge Built-in AI):** Runs locally inside your browser when experimental Prompt API (`LanguageModel` / `window.ai`) is enabled—zero cloud upload.
3. **Local Ollama (`127.0.0.1:11434`):** Connect your own local LLM (`llama3.2`, `qwen2.5`, `gemma2`, `deepseek-r1`, etc.) on Windows/Linux/macOS for 100% offline private AI chat.
4. **12 World AI Platforms (1-Tap Launch):** Direct, unproxied access to **ChatGPT**, **Google Gemini**, **Duck.ai**, **Claude**, **DeepSeek**, **Grok**, **Perplexity**, **Microsoft Copilot**, **Meta AI**, **Mistral Le Chat**, **Qwen Chat**, and **HuggingChat**.

## 4. Navigation, Share & Instant Panic Wipe

- **Unified Back/Forward History:** Pressing **Back** navigates cleanly through open tab history and returns to the Home Screen before confirming exit—never unexpectedly closing your session.
- **One-Tap Native Share:** Tap the **Share** icon in the browser header to send any page URL using your device's native share sheet or copy it cleanly.
- **Tab Sleeper & Energy Saver:** Automatically pauses inactive tabs at minimal RAM usage and reduces GPU animations on battery-powered laptops and phones.
- **Panic Wipe:** One tap immediately clears open tabs, session history, temporary caches, and browsing state.
